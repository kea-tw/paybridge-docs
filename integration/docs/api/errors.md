# Коды ошибок

При ошибке API возвращает HTTP-статус и тело в едином формате:

```json
{
  "code": "INSUFFICIENT_FUNDS",
  "message": "Недостаточно средств на счёте плательщика",
  "traceId": "5f2c9a1e7b"
}
```

Указывайте `traceId` при обращении в поддержку: по нему находится вся история запроса.

| HTTP | `code` | Описание | Действие |
| --- | --- | --- | --- |
| 400 | `VALIDATION_ERROR` | Не заполнено обязательное поле или неверный формат. Подробности в поле `message`. | Исправить запрос. |
| 401 | `UNAUTHORIZED` | Токен не передан или истёк. | Получить новый токен. |
| 403 | `FORBIDDEN` | У клиента нет доступа к этому ТСП. | Проверить `merchantId`. |
| 404 | `NOT_FOUND` | Ссылка или платёж не найдены. | Проверить идентификатор. |
| 409 | `IDEMPOTENCY_CONFLICT` | Ключ уже использован с другим телом запроса. | Сгенерировать новый ключ для нового запроса. |
| 409 | `LINK_EXPIRED` | Срок действия платёжной ссылки истёк. | Создать новую ссылку. |
| 422 | `INSUFFICIENT_FUNDS` | Недостаточно средств у плательщика. | Сообщить плательщику. |
| 422 | `REFUND_EXCEEDS_AMOUNT` | Сумма возвратов превышает сумму платежа. | Уменьшить сумму возврата. |
| 429 | `RATE_LIMITED` | Превышен лимит: 50 запросов в секунду. | Повторить после паузы из заголовка `Retry-After`. |
| 503 | `NPS_UNAVAILABLE` | НПС временно недоступна. | Повторить с тем же `Idempotency-Key`. |
