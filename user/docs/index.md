# Кабинет ТСП

**Кабинет ТСП** — веб-приложение банка для торгово-сервисных предприятий (ТСП). В кабинете сотрудники ТСП выставляют счета юридическим лицам и следят за оплатами, которые проходят через Национальную платёжную сеть (НПС).

## Что можно сделать в кабинете

| Задача | Инструкция |
| --- | --- |
| Войти в кабинет первый раз | [Вход в кабинет](login.md) |
| Выставить счёт по платёжной ссылке или QR-коду | [Выставление счёта по ссылке](payment-link.md) |
| Найти платёж и оформить возврат | [Поиск платежа и возврат](refund.md) |

## Перед началом работы

Для входа в кабинет нужны ссылка на веб-приложение и учётные данные: логин и временный пароль. Их выдаёт банк при подключении ТСП.

## Куда обращаться

По всем вопросам работы в кабинете обращайтесь к **администратору кабинета**, сотруднику вашей компании, который отвечает за подключение к кабинету. Администратор разблокирует учётные записи и при необходимости передаёт обращение в банк.

В обращении укажите:

- что вы делали и какое сообщение появилось на экране;
- дату и время;
- ID платежа или ссылки, если вопрос о конкретной операции;
- снимок экрана, если он есть.

## Условные обозначения

| Обозначение | Что означает |
| --- | --- |
| Красные цифры на рисунках | Элементы интерфейса. В тексте номер указан в скобках, например **Создать** (4). |
| Полужирный шрифт | Названия разделов, кнопок и полей. |
| Курсив | Значения, которые нужно ввести или выбрать, например *24 часа*. |
